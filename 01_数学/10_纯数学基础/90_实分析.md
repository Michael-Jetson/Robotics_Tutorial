### 4 · 详细章节大纲

#### §1 · 实数系的完备性再审视 🔵⚡

> **衔接 A1**：A1 中已用 Dedekind 分割从 ℚ 构造 ℝ 并证明其为有序域。本节**从结果出发**，把完备性的四种等价表述串成一条分析工具链。

**§1.1 上下确界与最小上界性质**
sup/inf 的定义；最小上界性质（LUB）作为 ℝ 的**分析公理**的地位；证明 ℚ 不满足 LUB（√2 例）。

**§1.2 Archimedean 性质与 ℚ 的稠密性**
证明 Archimedean 性质由 LUB 导出；ℚ 在 ℝ 中稠密；无理数的稠密性。

**§1.3 完备性的四种等价刻画**
证明循环：**LUB ⇔ 单调有界收敛 ⇔ 闭区间套 ⇔ Bolzano–Weierstrass**。每一步给出完整证明；强调 Cauchy 完备性 + Archimedean ⇔ LUB。

**§1.4 扩展实数系 ℝ̄ 与 ∞ 的代数**
±∞ 的引入、运算约定、拓扑结构；为 §2 的 lim sup / lim inf 铺垫。

🤖 **Robotics Sidebar 1**：控制李雅普诺夫函数的下确界分析；数值优化中函数下界的严格意义。

#### §2 · ℝ 中序列与级数 🔵⚡📖

**§2.1 收敛、Cauchy 列、子列**
ε–N 定义；Cauchy 列与 ℝ 完备性的关系；子列收敛性与 B–W 定理。

**§2.2 lim sup 与 lim inf**
通过尾部 sup/inf 的单调性构造；**lim sup aₙ = lim sup aₙ 的部分极限的最大者**（完整证明）；Stolz–Cesàro 定理。

**§2.3 级数：收敛判别法全家桶**
比较、比值、根值、Cauchy 凝聚、Dirichlet、Abel 判别法；根值判别严于比值（例证）。

**§2.4 绝对收敛 vs 条件收敛**
绝对收敛 ⇒ 收敛；Cauchy 乘积（Mertens 定理）；为 §2.5 重排铺垫。

**§2.5 Riemann 重排定理 🔵**
**完整证明**：条件收敛级数的项可重排以收敛到任意实数，或发散至 ±∞。强调**绝对收敛的代数不变性**是泛函分析中的深刻命题。

🤖 **Robotics Sidebar 2**：强化学习中 discounted return ∑γᵏrₖ 的绝对收敛保证 policy evaluation 的良定义。

#### §3 · 度量空间上的连续性 🔵📖

> **衔接 A3**：A3 已建立度量空间、开/闭集、紧致、连通、Baire 纲。本节**不重证拓扑结构**，直接用这些工具做分析。

**§3.1 连续性的三种等价定义**
ε–δ / 序列 / 拓扑（开集原像为开）；在度量空间中三者等价（完整证明）。

**§3.2 紧集上的连续像**
**连续像为紧**（A3 结果的分析使用）→ 导出 **Extreme Value Theorem** 🔵（完整证明）。

**§3.3 连通集上的连续像**

**§3.4 单调函数的连续点集**
单调函数的不连续点至多可数（证明利用 ℚ 的可数稠密性）。

#### §4 · 一致连续与半连续 🔵

**§4.1 一致连续**

**§4.2 Lipschitz 与 Hölder 连续**
连续性强弱链：Lipschitz ⊂ Hölder ⊂ 一致连续 ⊂ 连续；反例分离各层。

**§4.3 下 / 上半连续**

#### §5 · 单变量微分学 🔵📖

**§5.1 导数定义与基本性质**
线性性、乘积、商、链式法则；可导 ⇒ 连续（反之不然：Weierstrass 处处连续无处可导函数，§7 给出）。

**§5.2 Rolle → Mean Value → Cauchy MVT 🔵**
完整证明链：Rolle 定理（EVT + Fermat 引理）→ Lagrange MVT → Cauchy 广义中值定理。

**§5.3 L'Hôpital 法则**
基于 Cauchy MVT 的完整证明；0/0 与 ∞/∞ 两种形式；常见误用分析。

**§5.4 Taylor 定理与余项 🔵**
完整证明三种余项形式：
- **Lagrange 余项**（用 Rolle 定理的归纳应用）
- **Cauchy 余项**（Cauchy MVT）
- **积分余项**（需 §6 结果，回溯补证）

**§5.5 凸函数与导数的单调性**（为 §15 铺垫）
C² 下 f ≥ 0 ⇔ 凸；一阶条件 f(y) ≥ f(x) + f'(x)(y−x)。

🤖 **Robotics Sidebar 4**：非线性动力学 ẋ = f(x,u) 在平衡点的 Taylor 展开 → 雅可比线性化 → LQR 设计的数学基础。

#### §6 · Riemann–Stieltjes 积分 🔵⚡

> **选择 R–S 而非纯 Riemann**：为 B2 测度论铺路（Lebesgue–Stieltjes），并直接服务于机器人中的分布函数积分。

**§6.1 分划、上下和、Darboux 可积性**
单调增积分子 α；上积分 = 下积分的**可积性定义**；比较 Riemann 版本。

**§6.2 可积性判据**
**Cauchy 判据**：∀ε, ∃ 分划 P, U(P,f,α)−L(P,f,α) < ε；**连续 ⇒ R–S 可积**（完整证明）；**单调 + α 连续 ⇒ 可积**；不连续点 Lebesgue 判据（叙述，严格证明推迟至 B2）。

**§6.3 积分的基本性质**
线性、区间可加、估值定理；换积分子（α 可微时 dα = α'dx）。

**§6.4 积分中值定理**
第一与第二中值定理（后者需 Abel 求和法）。

**§6.5 Fundamental Theorem of Calculus 🔵**
**完整证明两部分**：
- Part I：F(x) = ∫ₐˣf 在 f 连续点可导且 F' = f
- Part II：f = g' 连续 ⇒ ∫ₐᵇf = g(b)−g(a)

**§6.6 分部积分与变量替换**
基于 FTC 的严格推导；为 §14 多变量变量替换铺垫。

🤖 **Robotics Sidebar 5**：∫ g(x) dF(x) —— 随机系统中对分布函数 F 的 Stieltjes 积分；期望 E[g(X)] 的统一表述（跨越离散 / 连续分布）。

#### §7 · 函数序列与级数 · 一致收敛 🔵📖⚡

**§7.1 逐点 vs 一致收敛**
ε–N 定义对比；**sup 范数刻画** sup|fₙ−f| → 0；反例（fₙ(x) = xⁿ 在 [0,1]）。

**§7.2 一致收敛的 Cauchy 准则**
完整证明，为 §16 中 C(X) 完备性做铺垫。

**§7.3 一致收敛保持的性质 🔵**
**完整证明三大定理**：
1. 一致收敛 + 连续 ⇒ 极限连续
2. 一致收敛 + R–S 可积 ⇒ 可交换极限与积分
3. fₙ' 一致收敛 + fₙ(x₀) 收敛 ⇒ fₙ 一致收敛且 (lim fₙ)' = lim fₙ'（**注意顺序**）

**§7.4 Weierstrass M-判别法**
∑Mₙ 收敛 + |fₙ| ≤ Mₙ ⇒ ∑fₙ 一致收敛；应用：Weierstrass 处处连续无处可导函数构造。

**§7.5 幂级数 🔵**
Cauchy–Hadamard 收敛半径 R = 1/lim sup|aₙ|^(1/n)；**Abel 定理**：幂级数在收敛区间内闭一致收敛；逐项微分与积分合法性。

**§7.6 解析函数初步**
实解析 vs C^∞（反例 f(x) = e^(−1/x²)）；为 §9 Stone–Weierstrass 的必要性铺垫。

🤖 **Robotics Sidebar 6**：神经网络通用逼近定理（Cybenko, Hornik）的数学基础即**连续函数在紧集上可被某类函数一致逼近**；一致收敛保证训练损失与泛化损失的一致性。

#### §8 · 等度连续与 Arzelà–Ascoli 定理 🔵⚡

**§8.1 等度连续性定义**
点态等度连续 vs 一致等度连续；在紧空间上两者等价（完整证明）。

**§8.2 Arzelà–Ascoli 定理 🔵（完整证明）**
陈述：(X, d) 紧致度量空间，F ⊂ C(X) 满足 **(i) 逐点有界 (ii) 等度连续**，则 F 在 C(X) 范数下**相对紧**（即预紧）。
**证明路线**（Rudin 7.25 + Pugh 4.5 互补）：
1. 可分性：紧度量空间有可数稠密子集 {x_k}
2. Cantor 对角线法：取子列使之在每 x_k 收敛
3. 等度连续 + 稠密性 ⇒ 对角线子列在整个 X 上一致收敛

**§8.3 逆向与应用**
一致收敛 ⇒ 等度连续（必要性）；在 ODE 解族、最优控制中的紧致性应用。

🤖 **Robotics Sidebar 7**：**最优控制中轨迹集合的紧致性** —— 一族满足 Lipschitz 界的容许控制所对应的状态轨迹通过 A–A 定理在 C([0,T], ℝⁿ) 中预紧，从而保证最优轨迹存在（直接通往 B4 与 Pontryagin 原理）。

#### §9 · Stone–Weierstrass 定理 🔵⚡

**§9.1 Weierstrass 逼近定理**
[a,b] 上连续函数可被多项式一致逼近；Bernstein 多项式**构造性证明**（Pugh 风格）。

**§9.2 Stone–Weierstrass 定理（代数版本）🔵**
**完整证明**：X 紧 Hausdorff（可取紧度量空间），A ⊂ C(X, ℝ) 为子代数，若 (i) 含常数 (ii) 分离点，则 A 在 C(X) 中稠密。
**证明工具**：
- 引理：|t| 在 [−M,M] 可被多项式一致逼近（用 √t 的 Taylor 估计）
- A 的一致闭包对 max/min 封闭（格结构）
- 分离点 + 含常数 ⇒ ∀x≠y, ∀α,β ∃f ∈ A̅ 使 f(x)=α, f(y)=β
- 最终：用 max/min 构造任意 ε-逼近

**§9.3 复版本与反例**
复系数需要额外的"共轭闭"条件（否则反例：全纯多项式在圆盘上不稠密）。

🤖 **Robotics Sidebar 8**：**轨迹参数化**——多项式样条（B-spline, Bézier）能一致逼近任意 C⁰ 轨迹；深度学习中 ReLU 网络的通用逼近可以视为 S–W 在某类代数上的现代化版本。

#### §10 · 压缩映射原理 🔵

**§10.1 Banach 不动点定理 🔵（完整证明）**
陈述：(X, d) 完备度量空间，T : X → X 满足 d(T(x), T(y)) ≤ k·d(x,y)，k ∈ [0,1)，则 T 有唯一不动点 x\* 且 ∀x₀, Tⁿ(x₀) → x\*，**收敛速率** d(Tⁿx₀, x\*) ≤ kⁿ/(1−k) · d(x₀, Tx₀)。
**证明**：构造迭代序列；Cauchy 性由等比估计；完备性给极限；唯一性由压缩系数 < 1。

**§10.2 参数化版本**
T(x, λ) 对 λ 连续/可微 ⇒ 不动点 x\*(λ) 对 λ 连续/可微（**为 §12 IFT 证明做准备**）。

**§10.3 压缩映射的应用预览**
- Picard–Lindelöf 存在唯一性（完整证明推迟到 B4，此处给出**草图**：C([t₀−δ, t₀+δ], ℝⁿ) 上算子 T[φ](t) = x₀ + ∫ f(s, φ(s)) ds 在小区间上压缩）
- Newton 迭代局部超线性收敛
- §12 反函数定理

🤖 **Robotics Sidebar 9**：**ICP 算法**（Iterative Closest Point）、**Gauss–Newton** 在局部极小附近的收缩性；SLAM 中 factor graph 优化迭代的收敛性分析。

#### §11 · 多变量微分学 · 总导数 🔵⚡📖

> **严格性强调**：拒绝"偏导数存在 ⇒ 可微"的错误观念。正确定义从一开始就用线性映射。

**§11.1 方向导数与偏导数**
定义、与可微性的关系；**经典反例**：f(x,y) = xy²/(x²+y⁴) at (0,0)，所有方向导数存在但不连续。

**§11.2 Fréchet 可微（总导数）🔵**
**正确定义**：f : U ⊂ ℝⁿ → ℝᵐ 在 a 可微 ⇔ ∃ 线性 L : ℝⁿ → ℝᵐ 使
‖f(a+h)−f(a)−L(h)‖ = o(‖h‖), h → 0
L = Df(a)，矩阵表示为 Jacobian 矩阵。

**§11.3 可微的充分条件**
**所有偏导在 a 某邻域连续 ⇒ f 在 a 可微**（完整证明，用 MVT 分量逐个估计）。

**§11.4 链式法则 🔵**
完整矩阵形式证明 D(g∘f)(a) = Dg(f(a))·Df(a)；视作线性映射的复合。

**§11.5 Jacobian 矩阵与梯度**
∇f 与 Df 的关系；方向导数 = ∇f · v（f 实值时）。

🤖 **Robotics Sidebar 10**：**机器人正运动学** FK : 𝕊¹×ℝ^(n-1) → SE(3)；其 Jacobian 是机器人学中的核心对象（几何 / 分析雅可比）；奇异位形即 Rank(J) < max，对应 §12 反函数定理失效的点。

#### §12 · 反函数定理与隐函数定理 🔵⚡📖

> **本节为 B1 的最高潮**。两定理完整证明是 Layer-1 微分流形的基石。

**§12.1 预备：算子范数与 GL(ℝⁿ) 是开集**
‖L‖ = sup‖Lx‖/‖x‖；**GL(ℝⁿ) 在 Mat(n) 中开**（证：可逆矩阵的小扰动仍可逆，用 Neumann 级数）；L ↦ L⁻¹ 连续。

**§12.2 反函数定理 🔵（完整证明：Rudin 9.24 路径）**
陈述：f ∈ C¹(U, ℝⁿ), a ∈ U, Df(a) 可逆，则存在 a 的邻域 V 与 f(a) 的邻域 W，使 f : V → W 为 C¹ 同胚；且
D(f⁻¹)(f(x)) = [Df(x)]⁻¹

**证明四步（完整）**：
1. **归约**：WLOG a = 0, f(0) = 0, Df(0) = I
2. **压缩映射**：对 y 在 0 附近，定义 φ_y(x) = x + y − f(x)，证明在小球上压缩（压缩常数 ≤ 1/2，用 Df 连续 + Df(0)=I）
3. **存在唯一** x = f⁻¹(y)：§10 Banach 不动点定理给出
4. **f⁻¹ 的 C¹ 性**：用 (1) 推出 f⁻¹ Lipschitz；进而推出 f⁻¹ 可微且导数为 [Df]⁻¹；再用 L ↦ L⁻¹ 连续推出 C¹

**§12.3 隐函数定理 🔵（从 IFT 导出）**
陈述：F : ℝⁿ × ℝᵐ → ℝᵐ，F(a,b)=0，∂F/∂y(a,b) 可逆，则存在邻域 U ∋ a、V ∋ b 与唯一 C¹ 函数 g : U → V 使 F(x, g(x)) = 0。
**证明**：定义 Φ(x,y) = (x, F(x,y))，验证 DΦ(a,b) 可逆，用 IFT 于 Φ；取投影得 g。
**导数公式**：Dg(x) = −[∂F/∂y]⁻¹·[∂F/∂x]。

**§12.4 秩定理（预告 Layer-1）**
局部形式：若 rank(Df) 在 a 附近恒为 r，存在局部坐标使 f 化为 (x₁,...,xₙ) ↦ (x₁,...,xᵣ,0,...,0)。仅叙述，证明推迟至 Layer-1。

🤖 **Robotics Sidebar 11**：**逆运动学局部存在性** —— 在非奇异位形 q₀ 处，FK 的 Jacobian 满秩，由 IFT 保证逆运动学 IK = FK⁻¹ 在 p₀ = FK(q₀) 的邻域内 C¹ 存在且唯一；奇异位形处必须使用伪逆或其他正则化。**隐函数定理**保证约束流形 { q : h(q) = 0 } 局部为光滑子流形（Layer-1 入口）。

#### §13 · 高阶导数、Taylor 展开与临界点分类 🔵

**§13.1 高阶 Fréchet 导数**
D²f(a) ∈ L(ℝⁿ, L(ℝⁿ, ℝᵐ)) ≅ Bilinear(ℝⁿ × ℝⁿ, ℝᵐ)；**Schwarz 定理**：∂²f/∂xᵢ∂xⱼ = ∂²f/∂xⱼ∂xᵢ 当 C²（完整证明用 MVT）。

**§13.2 ℝⁿ 中 Taylor 定理**
多重指标记号 α = (α₁,...,αₙ)；多元 Taylor 公式 + Lagrange 余项（完整证明：归约到单变量沿直线的情形）。

**§13.3 临界点二阶分类**
Hessian H = D²f(a)；正定 ⇒ 严格局部极小；负定 ⇒ 严格局部极大；不定 ⇒ 鞍点；半定：不确定（需高阶）。

**§13.4 Morse 引理（预告 Layer-1）**
非退化临界点附近存在局部坐标使 f(x) = f(a) + Σ ±xᵢ²；仅叙述。

🤖 **Robotics Sidebar 12**：**非线性动力系统线性化** ẋ = f(x,u) 在平衡 (x\*, u\*) 处展开 ẋ ≈ A(x−x\*) + B(u−u\*)，其中 A = ∂f/∂x, B = ∂f/∂u；Hartman–Grobman 定理保证拓扑等价（Layer-3 内容）。

#### §14 · ℝⁿ 中的 Riemann 积分 · Fubini · 变量替换 🔵⚡📖

**§14.1 矩形上的 Riemann 积分**
分划、上下和、可积性；推广 §6 到 ℝⁿ。

**§14.2 Jordan 可测集与零测集**
Jordan 外 / 内测度；一般区域上的积分 ∫_E f := ∫_R f·χ_E；**Jordan 零测 ⊂ Lebesgue 零测**（严格区别，Lebesgue 留给 B2）。

**§14.3 可积性判据（Riemann 版本）**
有界 f 在紧 Jordan 可测集 E 上 Riemann 可积 ⇔ 不连续点集为 **Lebesgue 零测**（Lebesgue 判据，叙述即可，完整证明在 B2）。

**§14.4 Fubini 定理（Riemann 版本）🔵**
陈述：f 在矩形 R = A×B 上 Riemann 可积，则 ∫_R f = ∫_A (∫_B f(x,y) dy) dx，**在所有累次积分存在的前提下**。完整证明（注意 Riemann 版本比 Lebesgue 版本限制更强）。

**§14.5 变量替换公式 🔵（Spivak Ch 3 路径的完整证明）**
陈述：φ : U → V 为 ℝⁿ 开集间 C¹ 微分同胚，f 在 V 上可积，则
∫_V f = ∫_U (f∘φ) |det Dφ|
**证明路线**：
1. 一维情形（§6.6 结果）
2. 基本变换（线性、平移、坐标置换）
3. 用 IFT 局部分解任意 C¹ 微分同胚为基本变换复合
4. 单位分拆（partition of unity）拼接（需 §3 紧集上的拓扑工具）

🤖 **Robotics Sidebar 13**：**位形空间体积积分** ∫_Q dq 在坐标变换下由 |det Dφ| 修正；**概率密度变换**：随机变量 Y = φ(X) 的密度 p_Y(y) = p_X(φ⁻¹(y))·|det Dφ⁻¹(y)|——粒子滤波、normalizing flows、SE(3) 上的不变测度的基础。
