## B4 常微分方程：机器人动力学与稳定性的语言

### 引言：为什么机器人学博士要深入学习 ODE

**机器人，本质上就是在流形上运动的 ODE**。把一台机械臂的拉格朗日动力学写出来，得到的永远是二阶常微分方程组 $M(q)\ddot q + C(q,\dot q)\dot q + G(q) = \tau$；化为一阶系统后，它是相空间 $T^*Q$ 上的向量场 $\dot x = f(x, u, t)$。控制器设计、轨迹优化、SLAM 估计、强化学习仿真——这些看似不同的技术栈，最底层的数学对象都是这条 ODE 及其流 $\phi_t$。没有 ODE 的严格理论，**"机器人仿真器给出的轨迹唯一吗？扰动下的误差有界吗？PD 控制真的稳定吗？步态极限环鲁棒吗？"** 这些博士论文中必然遇到的问题就只能凭经验回答。

B4 承接 B1–B3 的分析基础并为 Layer-1 与 Layer-2 铺路。**Picard–Lindelöf 存在唯一性**直接调用 B1 的压缩映射原理于 B3 意义下的 Banach 空间 $C([t_0-\delta,t_0+\delta],\mathbb R^n)$；**Peano 存在定理**需要 B1 的 Arzelà–Ascoli；**Gronwall 不等式**是 sim-to-real gap 的定量母定理；**矩阵指数 $e^{tA}$** 既连接 A2d 的 Jordan 形又是 SO(3)/SE(3) 指数映射的特例；**Lyapunov 直接法**是非线性控制（Slotine–Li、反馈线性化、backstepping、滑模）的通用武器；**Poincaré 映射与 Floquet 理论**支撑双足步行机器人极限环稳定性分析；**中心流形与分岔**解释步态切换；**辛积分器**决定 MuJoCo/Drake 长时间仿真的能量漂移。

本大纲共 16 节，按"存在性 → 正则性 → 线性理论 → 定性与几何 → 稳定性 → 周期/分岔 → 数值 → 接口"的顺序组织。**🔵 标记核心必修内容**（完整证明 + 机器人应用），**🟣 标记拓展内容**（证明骨架 + 进阶阅读）；**⚡ 标记需要动手推导/编程**的关键技能，**📖 标记纯理论阅读**。所有定理完整证明骨架必须掌握的共 10 个，汇总于 §B4.16 前的定理清单表。

### §B4.1 🔵 ODE 的基本概念、分类与机器人动力学的 ODE 形式

**ODE 是关于未知函数 $x(t)$ 及其导数的方程**。**阶**指出现的最高阶导数；**线性** $\dot x = A(t)x + g(t)$ 与**非线性** $\dot x = f(t,x)$；**自治** $\dot x = f(x)$（$f$ 不显含 $t$）与**非自治** $\dot x = f(t,x)$。本课程统一采用**初值问题 (IVP)** 标准形式：

$$\dot x = f(t,x), \quad x(t_0) = x_0, \quad f: U \subset \mathbb R \times \mathbb R^n \to \mathbb R^n$$

任何 $k$ 阶标量方程 $x^{(k)} = F(t,x,\dot x,\dots,x^{(k-1)})$ 通过状态扩张 $y_i = x^{(i-1)}$ 化为一阶系统，**这就是博士生必须形成的"状态空间反射"**。

**⚡ 预告**：自治系统 $\dot x = f(x)$ 的解 $\phi(t,x_0)$ 定义了相流（phase flow） $\phi_t: \mathbb R^n \to \mathbb R^n$，满足群性质 $\phi_{t+s} = \phi_t \circ \phi_s$，$\phi_0 = \mathrm{id}$。Layer-1 将把这一结构升级到流形上的单参数微分同胚群。

**机器人应用**（贯穿整门课）。**刚体机械臂的欧拉–拉格朗日方程** $M(q)\ddot q + C(q,\dot q)\dot q + G(q) = \tau$（$q \in \mathbb R^n$ 关节坐标）通过令 $x = (q, \dot q) \in \mathbb R^{2n}$ 化为一阶状态空间形式

$$\dot x = \begin{pmatrix}\dot q \\ M(q)^{-1}\bigl[\tau - C(q,\dot q)\dot q - G(q)\bigr]\end{pmatrix} =: f(x, \tau)$$

这就是 MuJoCo、Drake、Isaac Sim 所有积分器的"被积对象"。**每一次 `sim.step()` 本质都是在数值求解这个 ODE**。

### §B4.2 🔵 Picard–Lindelöf 存在唯一性定理（完整证明）

**定理（Picard–Lindelöf, 1890, 1894）**：设 $f$ 在 $R = \{(t,x) : |t-t_0| \leq a, \|x-x_0\| \leq b\}$ 上连续，且对 $x$ **Lipschitz 连续**：$\|f(t,x_1) - f(t,x_2)\| \leq L\|x_1 - x_2\|$。则存在 $\delta = \min(a, b/M)$（$M = \sup_R \|f\|$）使 IVP 在 $[t_0-\delta, t_0+\delta]$ 上有唯一解 $x \in C^1$。

**完整证明骨架（⚡ 必须能独立复述）**：

(i) 把 IVP 改写为积分方程 $x(t) = x_0 + \int_{t_0}^t f(s, x(s))\,ds$。

(ii) 在 Banach 空间 $X = C([t_0-\delta, t_0+\delta], \bar B(x_0, b))$（配以上确界范数，由 B3）上定义 Picard 算子 $(Tx)(t) := x_0 + \int_{t_0}^t f(s, x(s))\,ds$。验证 $T: X \to X$ 自映。

(iii) 验证 $T$ 是**压缩映射**：$\|Tx - Ty\|_\infty \leq L\delta\|x-y\|_\infty$。若 $L\delta < 1$ 则由 B1 **Banach 不动点定理**存在唯一不动点 $x^*$，即唯一解。

(iv) 去掉 $L\delta < 1$ 限制：改用加权范数 $\|x\|_L := \sup_t e^{-2L|t-t_0|}\|x(t)\|$，则 $T$ 在整个 $\delta$ 上就是压缩。

**🔵 Lipschitz 的必要性**：仅连续不保证唯一性（见 §B4.3）。**局部 vs 全局**：$\delta$ 仅保证局部存在，全局由 §B4.4 延拓给出。

**机器人应用**。机器人动力学 $f(x, \tau) = \bigl(\dot q;\; M^{-1}[\tau - C\dot q - G]\bigr)$ 在有界状态集上 $C^1$（因为 $M(q) \succ 0$ 连续且 $M^{-1}$ 光滑），**自动满足 Lipschitz**；因此给定初始状态 $x_0$ 与控制输入 $\tau(t)$，关节轨迹**唯一存在**。这是"仿真器结果可复现"的数学前提。反例：若 $\tau(t, x)$ 不连续（如纯 sign 函数滑模），Lipschitz 失效，唯一性可能被破坏——这是 §B4.3 的主题。

### §B4.3 🟣 Peano 存在定理与唯一性的失效

**定理（Peano, 1886, 1890）**：$f$ 仅**连续**就能保证 IVP 有解（不保证唯一）。

**证明骨架**：构造 **Euler 折线**$x_n(t)$（步长 $h_n \to 0$），证该序列在 $[t_0-\delta, t_0+\delta]$ 上一致有界（$\|x_n\| \leq b$）且**等度连续**（$\|x_n(t)-x_n(s)\| \leq M|t-s|$）。由 B1 **Arzelà–Ascoli 定理**存在子列一致收敛到某 $x^*$，验证 $x^*$ 满足积分方程即为解。

**⚡ 非唯一性经典反例**：$\dot x = x^{2/3}$，$x(0) = 0$。$f(x) = x^{2/3}$ 连续但在 0 处 Hölder $2/3$ 而非 Lipschitz。解族（分段定义）：$x \equiv 0$ 与

$$x_c(t) = \begin{cases} 0 & t \leq c \\ \left(\frac{t-c}{3}\right)^3 & t > c \end{cases}, \quad c \geq 0 \text{ 任意}$$

每个 $x_c$ 满足 $x_c(0) = 0$（因为 $c \geq 0$ 时 $0 \leq c$），且满足 ODE（在 $t > c$ 上直接验证；在 $t = c$ 处右导数为 0 与 $0^{2/3}=0$ 一致）。不同的 $c$ 给出不同的分叉时刻——这正是 Lipschitz 失效导致唯一性丧失的本质：**无穷多解从同一初值在不同时刻分叉**。

**机器人应用**。**非光滑动力学**普遍存在：滑模控制的 sign 函数、刚性接触的法向碰撞、摩擦突变、液压阀切换。在这些情形下 Peano 给出解的存在但唯一性失效，仿真器选择哪条解完全取决于数值离散方式。**实践对策**：Filippov 解、DAE 形式、时间步进 LCP（Stewart–Trinkle）、松弛化（MuJoCo 的 soft contact）。Grizzle 学派处理双足机器人"脚掉地"的混合系统也是这个问题的变体。

### §B4.4 🔵 解的延拓与最大存在区间

**最大解（maximal solution）**：解 $x: J \to \mathbb R^n$ 不能延拓到更大区间。最大区间 $J_{\max} = (t_-, t_+)$ 总是开区间。

**定理**：最大解或者全局存在（$t_+ = +\infty$），或者**有限时间爆破**（$t_+ < \infty$ 且 $\lim_{t\to t_+^-}\|x(t)\| = \infty$）或**逸出紧集**（轨迹离开 $f$ 的定义域的任何紧子集）。

**全局存在的充分条件**。(i) **线性增长**：$\|f(t,x)\| \leq a(t)\|x\| + b(t)$，其中 $a,b \in L^1_{\mathrm{loc}}$，配合 §B4.5 Gronwall 即得 $\|x(t)\|$ 有界。(ii) **前向不变紧集**：若存在紧集 $K$ 使 $f$ 在 $\partial K$ 向内，则从 $K$ 出发的轨迹永不逃逸，全局存在。(iii) **Lyapunov 函数有界下有界上**：能量/体积守恒或耗散系统。

**⚡ 经典爆破例**：$\dot x = x^2$，$x(0)=1$ 解为 $x(t) = 1/(1-t)$，在 $t=1$ 爆破。

**机器人应用**。仿真中"**积分器发散**"就是 blow-up 的数值表现——非线性刚度项（软接触、神经网络控制器的高增益）常见。Drake 的 implicit Euler 在刚性区域稳定但不能挽救真正的有限时间爆破；此时需要回到建模层面（加阻尼、降增益、引入饱和）。Gronwall 给出的线性增长条件正好对应"有界控制 + Lipschitz 动力学 + 线性阻尼"——这是工业机器人在安全设计下不爆破的理论依据。

### §B4.5 🔵 Gronwall 不等式：sim-to-real gap 的母定理

**积分形式**：$u(t) \leq \alpha(t) + \int_{t_0}^t \beta(s)u(s)\,ds \Rightarrow u(t) \leq \alpha(t) + \int_{t_0}^t \alpha(s)\beta(s)\exp\!\Bigl(\int_s^t \beta(\tau)d\tau\Bigr)ds$。

**常用推论（常数版）**：$u(t) \leq C + K\int_{t_0}^t u(s)\,ds \Rightarrow u(t) \leq C e^{K(t-t_0)}$。

**微分形式**：$\dot u \leq \beta(t) u \Rightarrow u(t) \leq u(t_0)\exp\!\int_{t_0}^t \beta(s)ds$。

**完整证明**（常数版）：设 $v(t) = C + K\int_{t_0}^t u(s)ds$。则 $\dot v = K u \leq Kv$，$(ve^{-K(t-t_0)})' \leq 0$，故 $v(t) \leq v(t_0)e^{K(t-t_0)} = Ce^{K(t-t_0)}$，而 $u \leq v$ 得证。

**推论 1（连续依赖）**：$\dot x_i = f(t,x_i) + g_i(t)$（$i=1,2$），$f$ Lip 常数 $L$，$\|g_1-g_2\| \leq \varepsilon$，$\|x_1(t_0)-x_2(t_0)\| \leq \delta$。由 Gronwall：$\|x_1(t)-x_2(t)\| \leq (\delta + \varepsilon(t-t_0))e^{L(t-t_0)}$。**初值扰动与模型扰动都以指数速率放大**。

**机器人应用（核心）**。**sim-to-real gap 的定量界**：设真实系统 $\dot x = f(x) + \Delta(x)$（$\|\Delta\|\leq \varepsilon$ 为建模误差），仿真 $\dot{\hat x} = f(\hat x)$，相同初值。则 $\|x(t)-\hat x(t)\|\leq \frac{\varepsilon}{L}(e^{Lt}-1)$。这给出**仿真有效时长** $T \sim \frac{1}{L}\log(1 + L\tau/\varepsilon)$ —— $\tau$ 是可接受误差。PPO/SAC 在 Isaac 训练的策略，为什么在真机上几秒内就飘？因为 $L$ 大（高频刚性），$\varepsilon$ 不小（电机模型、接触、延迟）。**域随机化**的本质就是把 Gronwall 界变成期望界。Koopman 运算符、ALE、Neural ODE 的误差分析同理。

📖 **Khalil 3e Ch.3.4, Teschl §2.2, Hartman Ch.III** 都给严格证明。

### §B4.6 🔵 解对初值与参数的光滑依赖与变分方程

设 $\dot x = f(t, x, \mu)$，解记为 $\phi(t, t_0, x_0, \mu)$。

**定理 1（连续依赖，Gronwall 推论）**：$f$ 对 $(x,\mu)$ 连续、对 $x$ Lipschitz，则 $\phi$ 对 $(t_0, x_0, \mu)$ 联合连续。

**定理 2（可微依赖）**：若 $f \in C^1$，则 $\phi$ 对 $(x_0, \mu)$ 也是 $C^1$，并且 $Y(t) := \frac{\partial \phi}{\partial x_0}(t, t_0, x_0)$ 满足**变分方程（灵敏度方程）**

$$\dot Y = D_x f(t, \phi(t))\,Y, \qquad Y(t_0) = I$$

对参数的灵敏度 $Z(t) := \partial\phi/\partial\mu$ 满足 $\dot Z = D_x f\cdot Z + D_\mu f$，$Z(t_0) = 0$。

**定理 3（高阶）**：$f \in C^k \Rightarrow \phi \in C^k$（Peano–Hartman）。

**证明要点**：差商 $[\phi(t, x_0 + h e_i) - \phi(t, x_0)]/|h|$ 的收敛性由 Gronwall 控制，极限满足线性 ODE。

**机器人应用（极其核心）**。**轨迹优化中的梯度计算**有两条路：

1. **前向灵敏度**：同时积分 $\dot x = f$ 与 $\dot Y = D_x f\,Y + D_u f$。代价 $O(n \cdot m)$，$m$ 为参数数。iLQR/DDP 内核。
2. **伴随方法（adjoint）**：反向积分 $\dot \lambda = -D_x f^\top \lambda$ 得到梯度 $\nabla J$。代价 $O(n+m)$，独立于参数数——Pontryagin、Neural ODE (Chen 2018)、CasADi、Crocoddyl、TrajOpt 的核心。

**Floquet 乘子**（§B4.12）、**Lyapunov 指数**（用于混沌/可预测性）、**模型参数辨识** 都是变分方程的应用。Slotine 的自适应控制中"参数估计误差动力学"本质是联合系统的变分方程。

### §B4.7 🔵 线性系统：一般理论与矩阵指数

线性系统 $\dot x = A(t)x + g(t)$ 是**唯一能完全求解**的一大类。

**齐次系统**：$\dot x = A(t)x$。解空间是 $n$ 维线性空间。**基本解矩阵** $\Phi(t)$ 满足 $\dot \Phi = A\Phi$，$\det\Phi \neq 0$。**Wronskian**：$W(t) = \det \Phi(t)$ 满足 **Liouville 公式** $\dot W = \mathrm{tr}(A)\cdot W$。

**非齐次（常数变易公式）**：

$$x(t) = \Phi(t)\Phi(t_0)^{-1}x_0 + \int_{t_0}^t \Phi(t)\Phi(s)^{-1} g(s)\,ds$$

**常系数 $\dot x = Ax$**：$\Phi(t) = e^{tA}$，

$$x(t) = e^{(t-t_0)A}x_0 + \int_{t_0}^t e^{(t-s)A}g(s)\,ds$$

**机器人应用**。平衡点 $x^*$ 附近线性化 $\delta\dot x = A\delta x + B\delta u$（$A = D_x f|_{x^*}$，$B = D_u f|_{x^*}$）是**所有 LTI 控制理论的起点**：能控能观矩阵（$\mathcal C = [B,AB,\ldots,A^{n-1}B]$）、极点配置、LQR Riccati、$H_\infty$、Kalman 滤波。误差动力学 $\delta\dot x \approx A\delta x$ 与基本解矩阵 $e^{tA}$ 共同决定**局部轨迹跟踪误差的传播律**。

### §B4.8 🔵 矩阵指数：从幂级数到 SO(3)/SE(3)

**定义**：$e^{tA} := \sum_{k=0}^\infty \frac{t^k A^k}{k!}$，在 $\mathbb R^{n\times n}$ 上范数拓扑绝对收敛。

**基本性质**：(i) $\frac{d}{dt}e^{tA} = Ae^{tA} = e^{tA}A$；(ii) $e^{(s+t)A} = e^{sA}e^{tA}$；(iii) $AB=BA \Rightarrow e^{A+B}=e^Ae^B$；(iv) $(e^A)^{-1} = e^{-A}$；(v) $\det e^A = e^{\mathrm{tr}\,A}$；(vi) $\sigma(e^{tA}) = \{e^{t\lambda} : \lambda \in \sigma(A)\}$（谱映射）。

**⚡ 计算方法**。

1. **对角化**：$A = PDP^{-1} \Rightarrow e^{tA} = P\,\mathrm{diag}(e^{t\lambda_i})\,P^{-1}$。
2. **Jordan 形**（连接 A2d）：$A = PJP^{-1}$，$J = D+N$（$D$ 对角、$N$ 幂零可交换），$e^{tJ} = e^{tD}e^{tN}$，其中 $e^{tN} = \sum_{k=0}^{n-1}\frac{t^k N^k}{k!}$ 是**多项式有限和**。
3. **Putzer 算法**、**Cayley–Hamilton**、**Padé 逼近**（数值）。
4. **Laplace 变换**：$\mathcal L\{e^{tA}\} = (sI-A)^{-1}$。

**🔵 Rodrigues 公式——$\mathfrak{so}(3)$ 上指数映射的闭式解**。设 $\omega \in \mathbb R^3$，$[\omega]_\times \in \mathfrak{so}(3)$ 为其反对称矩阵，$\theta = \|\omega\|$，$\hat \omega = \omega/\theta$，则

$$e^{[\omega]_\times} = I + \sin\theta\,[\hat\omega]_\times + (1-\cos\theta)[\hat\omega]_\times^2 \;\in\; SO(3)$$

**证明要点**：$[\hat\omega]_\times^3 = -[\hat\omega]_\times$（Cayley–Hamilton + 反对称），故幂级数仅含偶偶/奇奇两类项，分别求和为 $\cos\theta$ 与 $\sin\theta$ 乘积。

**机器人应用（极其核心）**。(i) **SO(3)/SE(3) 指数映射**：姿态积分 $\dot R = R\,[\omega]_\times \Rightarrow R(t+\Delta t) = R(t)\,\exp([\omega]_\times \Delta t)$。(ii) **IMU 预积分**（Forster 等 2017, T-RO 33(1):1–21, DOI 10.1109/TRO.2016.2597321）：将高频 IMU 测量预积分为关键帧间的相对运动约束，需要流形上的指数/对数映射、右雅可比 $J_r(\phi)$，是 VINS-Mono、ORB-SLAM3、GTSAM 的核心。(iii) **Lie 群运动学积分器**：Munthe-Kaas 方法、Crouch–Grossman，保流形结构。(iv) **BCH 公式** $\log(e^X e^Y) = X+Y+\tfrac12[X,Y]+\cdots$ 给出近似合成的 Lie 代数表达，Layer-1 深入。

### §B4.9 🔵 自治系统的相平面几何与 Hartman–Grobman 定理

**平衡点** $x^*$：$f(x^*)=0$。线性化矩阵 $A = Df(x^*)$ 的谱 $\sigma(A)$ 决定局部几何。

**双曲平衡点**：$\sigma(A) \cap i\mathbb R = \emptyset$（无纯虚特征值）。

**二维相肖像分类**（$A \in \mathbb R^{2\times 2}$，迹 $\tau = \mathrm{tr}\,A$，行列式 $\Delta = \det A$，判别式 $\tau^2 - 4\Delta$）：

| 特征值类型 | 名称 | 几何 |
|---|---|---|
| $\lambda_1,\lambda_2 < 0$ 实 | 稳定结点 | 轨迹沿慢特征方向进入 |
| $\lambda_1,\lambda_2 > 0$ 实 | 不稳定结点 | 反向 |
| $\lambda_1 > 0 > \lambda_2$ | 鞍点 | 稳定/不稳定流形十字 |
| $\alpha \pm i\beta$，$\alpha<0$ | 稳定焦点 | 螺旋进入 |
| $\alpha \pm i\beta$，$\alpha>0$ | 不稳定焦点 | 螺旋发散 |
| $\pm i\beta$（$\alpha=0$） | 中心 | 周期轨（非双曲！）|

**🔵 定理（Hartman–Grobman, Hartman 1960, Grobman 1959）**：若 $x^*$ 是**双曲**平衡点，则存在 $x^*$ 的邻域与 $0 \in \mathbb R^n$ 的邻域之间的**同胚 $h$**，使非线性流与线性流 $e^{tA}$ **局部拓扑共轭**：$h\circ\phi_t = e^{tA}\circ h$。

**证明骨架（⚡ 掌握思路即可）**：谱分解 $\mathbb R^n = E^s \oplus E^u$，构造 $h = \mathrm{id} + g$，$g$ 由 Banach 不动点在适当函数空间上求得；关键是利用双曲性给出的 $e^{tA}$ 在 $E^s, E^u$ 上的指数压缩/膨胀。完整证明见 Hartman Ch.IX §§7–9 或 Chicone Ch.4。

**⚠️ 光滑性警告**：$h$ 一般仅是**同胚而非微分同胚**，即使 $f \in C^\infty$ 也一样（Hartman 反例）。光滑等价需要**无共振**（Sternberg 定理）。

**机器人应用**。(i) **倒立摆**：上平衡点 $(\pi, 0)$ 是鞍点（$\lambda = \pm\sqrt{g/\ell}$），下平衡点 $(0,0)$ 是中心（有摩擦时变焦点）。H–G 保证局部线性控制器在真实非线性系统上定性行为正确。(ii) **PD 控制的稳定焦点**：$\ddot q + k_d \dot q + k_p q = 0$ 欠阻尼时稳定焦点，临界阻尼结点，过阻尼慢结点——增益整定图谱。(iii) **局部 LQR**有效性的理论保证来自 H–G。

### §B4.10 🔵 Lyapunov 稳定性理论：非线性控制的通用武器

**定义（$x^* = 0$ 为平衡点）**。

- **稳定（Lyapunov sense）**：$\forall \varepsilon>0,\exists \delta>0: \|x_0\|<\delta \Rightarrow \|x(t)\|<\varepsilon,\,\forall t\geq 0$。
- **渐近稳定**：稳定 + $\exists r>0: \|x_0\|<r \Rightarrow x(t)\to 0$。
- **指数稳定**：$\exists \alpha,\lambda>0: \|x(t)\|\leq \alpha\|x_0\|e^{-\lambda t}$。

**🔵 Lyapunov 直接法（第二法）**。**Lyapunov 函数** $V: U\to \mathbb R$ 是 $C^1$、正定（$V(0)=0, V(x)>0$ 对 $x\neq 0$）函数。沿轨迹导数 $\dot V(x) := \nabla V(x)\cdot f(x)$。

**定理（Lyapunov 1892）**：
1. $\dot V \leq 0$ ⇒ $x^*$ 稳定。
2. $\dot V < 0$（$x\neq 0$）⇒ 渐近稳定。
3. 加上**径向无界** $V(x)\to\infty$ ⇒ 全局渐近稳定。
4. $\dot V \leq -cV$ ⇒ **指数稳定**（率 $c/2$）。

**证明思路**：$\dot V \leq 0$ 则 $V(x(t))\leq V(x_0)$，$V$ 正定保证 $x(t)$ 在小邻域；$\dot V<0$ 严格下降 + $V\geq 0$ 下有界 ⇒ $V\to V_\infty$，取 $\omega$-极限集论证 $V_\infty=0$。

**🔵 LaSalle 不变原理（LaSalle 1960, IRE Trans. Circuit Theory CT-7: 520–527）**。若 $\dot V \leq 0$（仅半负定！），$\Omega$ 紧正不变，则所有轨迹收敛到 $M := \{\dot V = 0\}$ 中**最大不变集**。

**意义**：摆脱 $\dot V < 0$ 严格性限制——机械系统中 $\dot V$ 常仅对速度负定，LaSalle 是救星。

**证明**：$\omega(x_0)$ 非空紧不变 ⊆ $\{\dot V = 0\}$，由极大不变性落入 $M$。

**机器人应用（极其核心）**。

1. **PD 重力补偿控制**（Takegaki–Arimoto 1981, *J. Dyn. Syst. Meas. Control* 103: 119–125）：$\tau = -K_p(q-q_d) - K_d \dot q + G(q)$，Lyapunov 函数 $V = \tfrac12 \dot q^\top M \dot q + \tfrac12(q-q_d)^\top K_p(q-q_d)$，$\dot V = -\dot q^\top K_d \dot q \leq 0$（仅半负定）。LaSalle ⇒ $\dot q\to 0 \Rightarrow q\to q_d$。**这是机器人学最著名的稳定性证明**。
2. **Slotine–Li 自适应控制**（Slotine & Li 1987, *IJRR* 6(3):49–59, DOI 10.1177/027836498700600303）：利用反对称性 $\dot M - 2C$ 与参数线性化 $Y(q,\dot q,\ddot q)a = \tau$，Lyapunov 函数 $V = \tfrac12 s^\top M s + \tfrac12 \tilde a^\top \Gamma^{-1}\tilde a$（$s$ = 滑动面，$\tilde a$ = 参数误差），$\dot V = -s^\top K_D s \leq 0$，LaSalle ⇒ 跟踪误差收敛。
3. **计算力矩法、反馈线性化、能量整形、IDA-PBC、无源性控制**、**barrier function**（Ames 等 CBF 理论）统统是 Lyapunov 的变体。

### §B4.11 🔵 线性系统稳定性与 Lyapunov 方程

**Hurwitz 矩阵**：$A$ 的所有特征值有严格负实部。

**定理（Lyapunov 方程等价性）**：以下等价：
1. $A$ Hurwitz。
2. $\forall Q \succ 0$，**Lyapunov 方程** $A^\top P + PA = -Q$ 有唯一解 $P \succ 0$。
3. $\exists Q \succ 0, P \succ 0$ 满足上式。

**完整证明**：
- (1⇒2) 构造 $P := \int_0^\infty e^{tA^\top} Q e^{tA}\,dt$。$A$ Hurwitz ⇒ $\|e^{tA}\|\leq C e^{-\alpha t}$ ⇒ 积分绝对收敛。直接验证 $A^\top P + PA = [e^{tA^\top}Qe^{tA}]_0^\infty = -Q$。$P\succ 0$ 由 $Q\succ 0$ 与 $e^{tA}$ 可逆。
- (2⇒3) 平凡。
- (3⇒1) 取 Lyapunov 函数 $V = x^\top Px$，$\dot V = x^\top(A^\top P + PA)x = -x^\top Q x < 0$ ⇒ 渐近稳定 ⇒ 特征值实部 $<0$。

**机器人应用**。(i) **连续时间 LQR**：$\min\int(x^\top Qx + u^\top Ru)dt$ s.t. $\dot x = Ax + Bu$，最优反馈 $u = -R^{-1}B^\top P x$，$P$ 满足**代数 Riccati 方程** $A^\top P + PA - PBR^{-1}B^\top P + Q = 0$。闭环 $A_c = A - BR^{-1}B^\top P$ 自动满足 $A_c^\top P + PA_c = -Q - PBR^{-1}B^\top P \prec 0$——**Riccati 解 $P$ 同时是闭环系统的 Lyapunov 矩阵**。(ii) **观测器误差收敛**（对偶）。(iii) **$H_2/H_\infty$、LMI、凸综合**（Boyd 等）全部建立在 Lyapunov 方程之上。

### §B4.12 🔵 周期轨道、Poincaré 映射与 Floquet 理论

**周期解**：$x(t+T) = x(t)$。**极限环**：孤立周期轨道。

**🔵 Poincaré 映射**。取横截面 $\Sigma$（$f$ 处处非切于 $\Sigma$）穿过周期轨道 $\gamma$ 一点 $p^*$。**首次回归映射** $P: \Sigma \to \Sigma$ 将 $p\in\Sigma$ 映到轨迹下次穿 $\Sigma$ 的点。$p^*$ 是 $P$ 的不动点；$\gamma$ 稳定 $\iff p^*$ 是 $P$ 的稳定不动点 $\iff DP(p^*)$ 的特征值模 $<1$。**将连续极限环稳定性降一维为离散映射稳定性**。

**🔵 Floquet 定理（Floquet 1883, *Ann. Sci. ENS*）**：线性周期系统 $\dot x = A(t)x$，$A(t+T)=A(t)$ 的基本解矩阵可写为 $\Phi(t) = P(t) e^{tB}$，$P(t+T)=P(t)$，$B\in\mathbb C^{n\times n}$ 常值。$e^{TB}$ 称**单值（monodromy）矩阵**，其特征值 $\rho_i$ 为 **Floquet 乘子**；$\mu_i = \frac{1}{T}\log\rho_i$ 为 **Floquet 指数**。周期轨道稳定 $\iff$ 所有 $|\rho_i|<1$（除了沿 $\gamma$ 方向平凡的 $\rho = 1$）。

**证明骨架**：周期性 ⇒ $\Phi(t+T)$ 也是基本解矩阵 ⇒ $\Phi(t+T) = \Phi(t) C$（常数矩阵 $C=\Phi(T)$）。取 $B$ 使 $e^{TB}=C$ 并令 $P(t) = \Phi(t)e^{-tB}$，验证 $P$ 周期。

**机器人应用（极其核心）**。**双足/多足步行机器人极限环稳定性**：Grizzle 学派（Westervelt, Grizzle, Chevallereau, Choi, Morris《Feedback Control of Dynamic Bipedal Robot Locomotion》CRC 2007；以及 Grizzle, Abba, Plestan 2001 IEEE TAC "Asymptotically stable walking for biped robots"）用**混合零动力学（Hybrid Zero Dynamics, HZD）**将步态降维到 1D 零动力流形，Poincaré 映射的稳定性由该流形上的 1D 映射的 Floquet 乘子判定。ASIMO、Cassie、Digit、MIT Cheetah 的步行控制器设计都依赖此框架。

### §B4.13 🟣 二维全局理论：Poincaré–Bendixson 定理

**🔵 Poincaré–Bendixson 定理（Poincaré 1881–86；Bendixson 1901）**：设 $f\in C^1(\mathbb R^2)$，$\gamma$ 为向前有界轨道，其 $\omega$-极限集 $\omega(\gamma)$ 不含平衡点，则 $\omega(\gamma)$ 是**闭轨（周期轨）**。

**意义**：二维自治系统里**不可能有混沌**；渐近行为只有三类——平衡点、闭轨、连接平衡点的同宿/异宿环（graphic）。

**证明骨架**：关键是 Jordan 曲线定理（平面拓扑）——轨迹不能自交，横截线单调性（一条横截线上 $\omega$-极限点连续轨迹段上单调）。见 Teschl §7.3 或 Chicone Ch.1.8。

**Bendixson–Dulac 判据**（排除极限环）：若 $\mathrm{div}\,f$ 在单连通域 $D$ 上不变号且不恒为 0，则 $D$ 内无闭轨。Dulac 推广：存在光滑 $B(x)>0$ 使 $\mathrm{div}(Bf)$ 不变号。

**指标理论**：闭轨必围绕**指数和为 $+1$** 的平衡点集合（每个焦/结/中心指数 $+1$，鞍 $-1$）。

**机器人应用**。(i) **van der Pol 振荡器** $\ddot x - \mu(1-x^2)\dot x + x = 0$ 是平面极限环原型；在步行机器人中央模式发生器（CPG）中用作基础单元（Ijspeert, Righetti）。(ii) **2D 倒立摆（无摩擦）**不可能有极限环（Hamiltonian 系统 $\mathrm{div}\,f = 0$ 保守）。(iii) **更高维即可混沌**——三连杆机器人的自由落体可能混沌（Spong 的 Acrobot 研究），这是 $n\geq 3$ 的机器人需要 §B4.14 更强工具的原因。

### §B4.14 🟣 中心流形与分岔简介

**🔵 中心流形定理（Kelley 1967; Carr 1981）**。设 $x^* = 0$ 非双曲，$A = Df(0)$ 谱分解 $\sigma(A) = \sigma_s \cup \sigma_c \cup \sigma_u$（实部 $<0,=0,>0$）。相应不变子空间 $E^s, E^c, E^u$。则存在局部不变流形 $W^s, W^c, W^u$（切于 $E^s, E^c, E^u$）。$W^s, W^u$ 唯一且 $C^k$；$W^c$ 存在但**不唯一**，$C^k$（任意 $k$，但非 $C^\infty$ in general）。

**降维原理**：系统局部动力学等价于限制在 $W^c$ 上的方程——**维数从 $n$ 降到 $\dim E^c$**，通常 1–2 维。

**基本分岔（一维）**：
- **鞍-结（fold/saddle-node）**：$\dot x = \mu - x^2$。$\mu<0$ 无平衡；$\mu=0$ 半稳定；$\mu>0$ 两平衡点 $\pm\sqrt\mu$。
- **跨临界（transcritical）**：$\dot x = \mu x - x^2$。
- **叉形（pitchfork）**：$\dot x = \mu x - x^3$（超临界）。
- **Hopf 分岔**（二维，Hopf 1942, *Ber. Math.-Phys. Kl. Sächs. Akad. Wiss.* 94:1–22）：一对共轭复特征值穿越虚轴，产生/消灭极限环。超临界 Hopf：稳定焦点 → 不稳定焦点 + 小幅稳定极限环。

**机器人应用**。(i) **步态切换**（走/跑/跳）常对应 Hopf 或 period-doubling 分岔（Holmes, Full 等的腿式机器人动力学研究）。(ii) **参数扫描**——Ijspeert 的 salamander 机器人水陆两栖步态由 CPG 参数 Hopf 分岔切换。(iii) **模型预测控制中的可行性边界**可对应鞍-结分岔——控制增益扫描中突然失控的门槛。(iv) **反向驾驶的汽车模型**在速度 $v$ 超过某阈值时发生 Hopf（蛇行失稳）。

### §B4.15 🔵 数值方法：积分器选择决定仿真质量

**显式 Euler**：$x_{n+1} = x_n + h f(t_n, x_n)$，局部误差 $O(h^2)$、全局 $O(h)$。**条件稳定**（稳定域 $|1+h\lambda|<1$ 小圆盘）。

**Runge–Kutta 4 (RK4)**：经典四阶方法，局部 $O(h^5)$、全局 $O(h^4)$。机器人仿真默认选择。

**隐式方法**。**隐式 Euler** $x_{n+1} = x_n + h f(t_{n+1}, x_{n+1})$；**梯形法**（Crank–Nicolson）$x_{n+1} = x_n + \tfrac{h}{2}(f_n + f_{n+1})$。**A-稳定**（稳定域含整个左半平面），适合**刚性系统**。

**刚性 (stiff) 系统**：特征值模长相差极大（如 $\lambda_1 = -1, \lambda_2 = -10^6$）。显式方法步长受最快模式限制（$h \lesssim 1/|\lambda_2|$），计算不可行；隐式方法可用大步长。机器人中**刚性接触、弹簧-质量阻尼、PD 高增益**都产生刚性。

**🔵 辛积分器（保结构方法）**。哈密顿系统 $\dot q = \partial H/\partial p,\,\dot p = -\partial H/\partial q$ 保辛 2-形式 $\omega = dp\wedge dq$ 与能量 $H$。标准 RK 方法**不保辛**，长时间仿真**能量漂移**。**辛 Euler、Verlet（leapfrog）、Störmer–Verlet**保辛，能量有界振荡但不单调漂移。参考文献：Hairer, Lubich, Wanner *Geometric Numerical Integration* (Springer 2006)；Leimkuhler & Reich *Simulating Hamiltonian Dynamics* (Cambridge 2004)。

**Lie 群积分器**：Munthe-Kaas (1998) 方法，保 SO(3)/SE(3) 流形结构；Drake、Pinocchio、Crocoddyl 的核心。

**机器人应用**。**MuJoCo** 默认用半隐式 Euler（对软接触 LCP 稳定）；**Drake** 提供 RK2/3、Radau5（隐式刚性）、symplectic Euler；**Isaac Sim** 基于 PhysX 用半隐式 PGS 求解器；**Bullet** 的接触 LCP + Featherstone 算法。**长时间仿真（太空机器人、轨道、生物运动能量守恒研究）必须用辛积分器**；**刚性 PD 高增益必须用隐式**；**一般机器臂轨迹仿真 RK4 足矣**。**Hairer–Lubich–Wanner 的"修改方程"理论**给出 $h$ 阶修正 Hamilton 函数 $\tilde H$ 使数值轨迹精确是 $\tilde H$ 的流——这是"辛积分器为何能量不漂移"的深层解释。

📖 Iserles *A First Course in the Numerical Analysis of Differential Equations*。

### §B4.16 与后续任务的接口总结

**→ Layer-1（微分流形）**。(i) 向量场 = 流形 $M$ 切丛 $TM$ 的截面；ODE $\dot x = X(x)$ 就是 $X$ 的积分曲线；解产生流 $\phi_t: M\to M$。(ii) Lie 导数 $\mathcal L_X f = \frac{d}{dt}\big|_0 (f\circ\phi_t)$、Lie 括号 $[X,Y] = \mathcal L_X Y$ 的 ODE 解释。(iii) **Frobenius 定理**关于 involutive 分布的可积性是 ODE 存在性在流形上的推广——反馈线性化（Isidori）核心。

**→ Layer-1（李群）**。(i) 左不变向量场的 ODE $\dot g = gX$（$X\in\mathfrak g$）的解 $g(t) = g_0 \exp(tX)$ 定义**指数映射** $\exp:\mathfrak g\to G$。(ii) **Baker–Campbell–Hausdorff 公式** $\log(e^X e^Y) = X+Y+\tfrac12[X,Y]+\tfrac{1}{12}([X,[X,Y]]+[Y,[Y,X]])+\cdots$ 由 ODE $\dot Z(t) = \cdots$ 在 $\mathfrak g$ 上的积分推出。(iii) **对数映射**为 $\exp$ 局部逆；SO(3) 上 $\log R = \frac{\theta}{2\sin\theta}(R-R^\top)^\vee$。

**→ Layer-2（非线性控制）**。(i) **反馈线性化**（Isidori *Nonlinear Control Systems* 3e）——通过坐标变换把非线性系统化为可控标准型，关键工具是 Lie 导数与相对阶。(ii) **Backstepping**（Krstić, Kanellakopoulos, Kokotović 1995）——递推 Lyapunov 构造。(iii) **滑模控制**（Utkin, Slotine）——基于 sign 非光滑 ODE 与 Filippov 解。(iv) **被动性与 IDA-PBC**（Ortega, van der Schaft）——能量整形的 Lyapunov 证明。

**→ Layer-2（最优控制）**。**Pontryagin 最大原理**的状态-协态方程 $\dot x = \partial H/\partial \lambda,\,\dot\lambda = -\partial H/\partial x$ 是**哈密顿 ODE**。两点边值问题 (TPBVP)、shooting、collocation、DDP 全部是 ODE 数值问题。Pontryagin, Boltyanskii, Gamkrelidze, Mishchenko *The Mathematical Theory of Optimal Processes* (1962) 是源头。

**→ Layer-2（机器人仿真）**。Featherstone *Rigid Body Dynamics Algorithms* (Springer 2008) 的空间代数 + RNEA/ABA；MuJoCo Todorov 2012 IROS；Drake Tedrake 组；Pinocchio Carpentier 2019——都是 ODE 右端 $f(x,u)$ 的高效计算 + §B4.15 积分器的工程实现。

### 经典论文清单

**基础理论（19 世纪–20 世纪初）**

1. **Picard, É.** (1890). *Mémoire sur la théorie des équations aux dérivées partielles et la méthode des approximations successives*. Journal de Mathématiques Pures et Appliquées, 4e série, 6: 145–210. — 提出**逐次逼近法**，后成为 Banach 不动点法的原型。机器人学中 Picard 迭代是显式求解 IVP 的蓝本、Lipschitz 条件的最早系统分析。
2. **Lindelöf, E.** (1894). *Sur l'application de la méthode des approximations successives aux équations différentielles ordinaires du premier ordre*. Comptes Rendus Acad. Sci. Paris 118: 454–457. — 将 Picard 方法形式化为现代版本。
3. **Peano, G.** (1886). *Sull'integrabilità delle equazioni differenziali di primo ordine*. Atti Accad. Sci. Torino 21: 677–685；(1890) *Demonstration de l'intégrabilité des équations différentielles ordinaires*. Math. Ann. 37: 182–228. — **仅需连续性即可保证存在**的最经典结果。对应机器人中非光滑接触/滑模的存在性基础。
4. **Gronwall, T. H.** (1919). *Note on the derivatives with respect to a parameter of the solutions of a system of differential equations*. Annals of Mathematics (Second Series) 20(4): 292–296. doi:10.2307/1967124. — **Gronwall 不等式**原始论文；Bellman 1943 推广积分形式。机器人 sim-to-real gap 与鲁棒性分析的母定理。

**稳定性理论**

5. **Lyapunov, A. M.** (1892). *The general problem of the stability of motion* (俄语博士论文，Kharkov)。法译 1907 Annales Faculté Sciences Toulouse 9: 203–474；英译 **Fuller, A. T.** (1992) *Int. J. Control* 55(3): 531–773 (centenary issue)。 — **Lyapunov 直接法 + 线性化方法**的奠基作。所有非线性控制稳定性证明的根基。
6. **Hurwitz, A.** (1895). *Über die Bedingungen, unter welchen eine Gleichung nur Wurzeln mit negativen reellen Teilen besitzt*. Math. Ann. 46: 273–284. — **Hurwitz 判据**。线性控制系统稳定性图形化判据的起点。
7. **LaSalle, J. P.** (1960). *Some extensions of Liapunov's second method*. IRE Transactions on Circuit Theory CT-7(4): 520–527. doi:10.1109/TCT.1960.1086720. — **LaSalle 不变原理**。PD 控制、Slotine–Li 自适应、能量整形稳定性证明的通用工具（机械系统 $\dot V$ 仅半负定时的救星）。
8. **Grobman, D. M.** (1959). *Homeomorphism of systems of differential equations*. Dokl. Akad. Nauk SSSR 128: 880–881；**Hartman, P.** (1960). *A lemma in the theory of structural stability of differential equations*. Proc. AMS 11(4): 610–620. — **Hartman–Grobman 定理**。双曲平衡点线性化的拓扑合理性——局部 LQR 控制器能推广到非线性系统的理论依据。

**几何动力系统**

9. **Poincaré, H.** (1881–1886). *Mémoire sur les courbes définies par une équation différentielle*. Journal de Mathématiques Pures et Appliquées, 3e série, 7: 375–422 (1881)；8: 251–296 (1882)；4e série, 1: 167–244 (1885)；2: 151–217 (1886). — 开创**几何定性理论**：相平面、极限环、Poincaré 映射、指数理论，现代动力系统的源头。
10. **Bendixson, I.** (1901). *Sur les courbes définies par des équations différentielles*. Acta Mathematica 24: 1–88. — 完善 Poincaré–Bendixson 定理并提出 Bendixson 判据。
11. **Floquet, G.** (1883). *Sur les équations différentielles linéaires à coefficients périodiques*. Annales Scientifiques de l'École Normale Supérieure, 2e série, 12: 47–88. — **Floquet 定理**。双足机器人步态稳定性分析的数学基础。
12. **Hopf, E.** (1942). *Abzweigung einer periodischen Lösung von einer stationären Lösung eines Differentialsystems*. Berichte Math.-Phys. Kl. Sächs. Akad. Wiss. Leipzig 94: 1–22. — **Hopf 分岔**。步态切换、CPG 极限环产生机制的典型分岔类型。
13. **Kelley, A.** (1967). *The stable, center-stable, center, center-unstable, unstable manifolds*. J. Differential Equations 3: 546–570；**Carr, J.** (1981). *Applications of Centre Manifold Theory*. Applied Math. Sciences 35, Springer. — **中心流形定理**。非双曲平衡点降维与分岔分析的标准工具。

**机器人与控制应用**

14. **Takegaki, M. & Arimoto, S.** (1981). *A new feedback method for dynamic control of manipulators*. ASME J. Dynamic Systems, Measurement, and Control 103(2): 119–125. doi:10.1115/1.3139651. — **PD + 重力补偿**稳定性证明，机器人控制最著名的 Lyapunov + LaSalle 应用。
15. **Slotine, J.-J. E. & Li, W.** (1987). *On the adaptive control of robot manipulators*. International Journal of Robotics Research 6(3): 49–59. doi:10.1177/027836498700600303. — **Slotine–Li 自适应控制器**，利用 $\dot M - 2C$ 反对称性与参数线性化的 Lyapunov 设计，至今仍是机器人自适应控制的标杆。
16. **Murray, R. M., Li, Z., & Sastry, S. S.** (1994). *A Mathematical Introduction to Robotic Manipulation*. CRC Press. ISBN 978-0-8493-7981-9. — 将 Lie 群指数映射、旋量、SE(3) 运动学系统化为机器人学标准语言。
17. **Grizzle, J. W., Abba, G., & Plestan, F.** (2001). *Asymptotically stable walking for biped robots: Analysis via systems with impulse effects*. IEEE Transactions on Automatic Control 46(1): 51–64；**Westervelt, E. R., Grizzle, J. W., Chevallereau, C., Choi, J. H., Morris, B.** (2007). *Feedback Control of Dynamic Bipedal Robot Locomotion*. CRC Press. — **混合零动力学 (HZD)**，用 Poincaré 映射 + Floquet 乘子证明双足步行极限环稳定性，ASIMO、Cassie、Digit 控制理论基础。
18. **Forster, C., Carlone, L., Dellaert, F., & Scaramuzza, D.** (2017). *On-manifold preintegration for real-time visual–inertial odometry*. IEEE Transactions on Robotics 33(1): 1–21. doi:10.1109/TRO.2016.2597321. — **IMU 预积分**流形化理论，用 SO(3) 指数映射 + 右雅可比，是 VINS-Mono、ORB-SLAM3、Kimera、OpenVINS 的数学内核。
19. **Hairer, E., Lubich, C., & Wanner, G.** (2006). *Geometric Numerical Integration: Structure-Preserving Algorithms for Ordinary Differential Equations*, 2nd ed. Springer Series in Computational Mathematics 31. — **辛积分器**权威参考；长时间机器人/空间仿真能量守恒的理论基础。
20. **Featherstone, R.** (2008). *Rigid Body Dynamics Algorithms*. Springer. ISBN 978-0-387-74314-1. — **空间代数 + RNEA/ABA 算法**。Pinocchio、Drake、Crocoddyl、MuJoCo 刚体 $f(x,u)$ 高效计算的基础。

### 接口总结：B4 如何服务后续路线

**总原则**：**凡机器人研究中出现的连续时间动力学，都是 B4 意义下的 ODE**；**凡稳定性/鲁棒性/收敛性论证，都至少隐含 B4 某个定理**。

| 下游 | 用到 B4 的哪部分 | 具体联系 |
|---|---|---|
| **Layer-1 微分流形** | §B4.1, §B4.7 | 向量场 = $TM$ 截面；积分曲线即 ODE 解；流 $\phi_t$ 生成单参数微分同胚群 |
| **Layer-1 李导数/Lie 括号** | §B4.1, §B4.6 | $\mathcal L_X f = d/dt(f\circ\phi_t)$；Frobenius 定理是流形版 Picard |
| **Layer-1 李群/指数映射** | §B4.8 | $\dot g = gX$ 解 = $\exp(tX)$；Rodrigues 公式是 $\mathfrak{so}(3)$ 版 $e^{tA}$ |
| **Layer-1 BCH 公式** | §B4.8 | $\log(e^X e^Y)$ 由 Lie 代数值 ODE 积分给出 |
| **Layer-2 非线性控制** | §B4.9, §B4.10, §B4.11 | 反馈线性化（Lie 导数）、backstepping（递推 Lyapunov）、滑模（Filippov 解）、被动性（能量 Lyapunov） |
| **Layer-2 最优控制** | §B4.2, §B4.7 | Pontryagin 状态-协态方程是哈密顿 ODE；TPBVP shooting/collocation |
| **Layer-2 机器人动力学仿真** | §B4.15 | 积分器选择（RK/隐式/辛/Lie 群）；MuJoCo, Drake, Isaac, Pinocchio |
| **Layer-2 步态规划与控制** | §B4.12, §B4.13, §B4.14 | HZD、Poincaré 映射、Floquet 乘子；CPG Hopf 分岔 |
| **Layer-2 轨迹优化** | §B4.6 | iLQR/DDP 前向灵敏度；Crocoddyl 伴随方法；Neural ODE |
| **Layer-2 SLAM/状态估计** | §B4.8 | IMU 预积分（Forster 2017）依赖 SO(3) 指数映射 |
| **Layer-2 强化学习仿真** | §B4.5, §B4.15 | Gronwall 界决定仿真有效时长与 sim-to-real gap；辛积分器减少长时间训练发散 |
| **Layer-2 鲁棒控制/ISS** | §B4.5, §B4.10 | 扰动下 Lyapunov 函数耗散率 + Gronwall 给出鲁棒界 |

**一句话总结**：B4 在本路线图中的地位，等于**泛函分析 B3 之于 Hilbert 空间理论**——它不是"终点产品"，而是几乎所有下游研究（控制、估计、优化、仿真、学习）的**共同数学基底**。掌握 B4 的 10 个核心证明 + SO(3)/SE(3) 指数映射 + Lyapunov/LaSalle + Poincaré–Floquet + 辛积分器五大支柱后，读者就具备了进入 Layer-1 流形几何与 Layer-2 机器人技术栈的**完整分析工具包**。
