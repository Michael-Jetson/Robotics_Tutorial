## 第一部分 · 群论 (§1–§7)

### §1. 群、子群、循环群、对称群 🔵

**来源领域.** 对称性抽象化（Galois, Cayley）；矩阵群（Lie, Klein）。
**前置依赖.** A1 等价关系与划分；A2 矩阵代数。
**主参考.** D&F 1.1–1.3, 1.6, 2.1–2.4, 3.2, 3.5 · Artin 2.1–2.8, 6.1–6.4 · Lang I.1–I.4 · Aluffi II.1–II.2, II.6, II.8.

#### 1.1 群公理与基本性质 📖 🔵
- 群定义：(G, ·, e) 满足结合律、单位元、逆元；幺半群 → 群的层级
- 单位元唯一性、逆元唯一性、消去律 **⚡小练习**
- 子群判定：一步检验 a, b ∈ H ⇒ ab⁻¹ ∈ H；有限子集判定

#### 1.2 陪集与 Lagrange 定理 📖 🔵
- 左/右陪集 gH, Hg；陪集划分 G（等价关系 g ∼ g' ⟺ g⁻¹g' ∈ H）— **直接调用 A1 等价类/划分定理**
- 指数 [G:H]；|gH| = |H|（通过双射 h ↦ gh）
- **Lagrange 定理**：|G| = [G:H]·|H|（有限群时）；三大推论（ord(g)∣|G|；g^|G| = e；素数阶群循环）
- ⚠️ **陷阱**：Lagrange 逆命题不成立（A_4 无 6 阶子群 — 经典反例）

#### 1.3 循环群与生成 📖 🔵
- ⟨g⟩ 的结构分类：同构于 ℤ 或 ℤ/nℤ（由 ord(g) 决定）
- 子群格；⟨S⟩ = 所有含 S 之子群之交
- 循环群的子群仍循环；n 阶循环群有唯一 d 阶子群（d ∣ n）

#### 1.4 对称群 S_n 与交错群 A_n 📖 🔵
- 置换的循环分解唯一性；符号映射 sgn: S_n → {±1} **（证明其良定义 — 易被跳过的严格点）**
- A_n = ker(sgn)，|A_n| = n!/2
- 转置生成 S_n；3-轮换生成 A_n（n ≥ 3）
- ⚫ 黑盒：A_n 对 n ≥ 5 为单群（延后在 §5 附近陈述并使用）

#### 1.5 二面体群 D_n 📖 🔵
- 作为正 n 边形的对称群，|D_n| = 2n
- 表示 ⟨r, s ∣ rⁿ = s² = e, srs = r⁻¹⟩
- D_n ⊂ O(2) 的矩阵实现

#### 🤖 机器人侧栏 1：SO(n) 与 SO(3) 作为矩阵李群（轴公理验证）
定义 **O(n) = {R ∈ GL_n(ℝ) : RᵀR = I}**，**SO(n) = O(n) ∩ {det = 1}**。显式验证群公理：
- 封闭：(AB)ᵀ(AB) = BᵀAᵀAB = I；det(AB) = 1
- 逆：A⁻¹ = Aᵀ ∈ O(n)
- 结合：矩阵乘法天然结合

SO(2) ≅ S¹ 是典范循环/连续例；**SO(2) 的有限子群正是循环群 ℤ/nℤ**（机器人转盘/轮子旋转对称性）；O(2) 的有限子群仅循环或二面体（Leonardo 定理，Artin 6.5）—— 直接对应 **n 足步行机器人**（六足 ↔ D_6）与 **径向对称末端执行器**。SO(3) 中心：Z(SO(3)) = {I}；双覆盖 SU(2) → SO(3)（核 {±I}）⇒ π_1(SO(3)) = ℤ/2 —— 解释为何无连续 3 参数全局无奇点坐标卡（Euler 角必奇）。  
**参考**：MLS 1994 Ch. 2；Chirikjian Vol. 2 Ch. 10；Selig 2005 Ch. 4。

### §2. 群同态与三大同构定理 🔵

**主参考.** D&F 3.1–3.3 · Artin 2.5, 2.6, 2.10, 2.12 · Lang I.2 · Aluffi II.4, II.7.

#### 2.1 同态的基本性质 📖 🔵
- 同态 φ: G → H；自动有 φ(e) = e、φ(g⁻¹) = φ(g)⁻¹
- ker φ ⊴ G；im φ ≤ H；φ 单射 ⟺ ker φ = {e}
- 同构；自同构群 Aut(G)；内自同构 Inn(G) ≅ G/Z(G)

#### 2.2 商群的泛性质 📖 🔵 ⚡
- 商映射 π: G → G/N 的泛性质：任何杀掉 N 的同态唯一分解过 G/N
- **此即 §15 "范畴中的余等化子" 的最早实例** — 先于范畴抽象体会之

#### 2.3 三大同构定理（完整证明）📖 🔵
1. **第一同构定理**：G/ker φ ≅ im φ
2. **第二同构定理（钻石）**：A ≤ G, B ⊴ G ⇒ AB/B ≅ A/(A∩B)
3. **第三同构定理**：K ⊴ H ⊴ G, K ⊴ G ⇒ (G/K)/(H/K) ≅ G/H
- ⚠️ **严格点**：每步都需验证陪集上映射的良定义性；勿跳过

#### 2.4 对应/格定理（第四同构定理）📖 🔵
- G/N 的子群 ↔ G 中含 N 的子群；保序、保指数、保正规性、保共轭
- 应用：计算 G/N 的结构只需研究 G 的子群格之上半部分

#### 🤖 机器人侧栏 2：det 同态与 SE(3) → SO(3)
- **det: GL_n(ℝ) → ℝ^×** 是典型同态，核为 SL_n(ℝ)
- **det: O(3) → {±1}** 的核为 SO(3)：O(3)/SO(3) ≅ ℤ/2（方向保持 vs 反向—— 机器人抓取手性）
- **忘记平移映射 SE(3) → SO(3), (R,t) ↦ R** 是满同态，核为 ℝ³；由第一同构定理：SE(3)/ℝ³ ≅ SO(3)（§6 再展开）

### §3. 正规子群与商群 🔵

**主参考.** D&F 3.1, 3.3 · Artin 2.10, 2.12 · Lang I.2, I.3 · Aluffi II.7.

#### 3.1 正规性的六大等价刻画 📖 🔵
(i) gNg⁻¹ ⊆ N；(ii) gNg⁻¹ = N；(iii) gN = Ng；(iv) N 是共轭类之并；(v) N 是某同态的核；(vi) 左右陪集划分相同

#### 3.2 商群构造 📖 🔵 ⚡
- 陪集乘法 (gN)(hN) = ghN 的良定义性 ⟺ N 正规
- 严格写出公理验证（易跳过）

#### 3.3 基本构造子群 📖 🔵
- 正规化子 N_G(H) = 使 H 成为正规子的最大子群
- 中心 Z(G)、换位子群 [G,G]、Abel 化 G/[G,G]（泛性质）
- 特征子群；Z(G), [G,G] 皆特征
- ⚠️ **严格点**：正规 ∘ 正规 ≠ 正规（经典反例 V_4 ⊴ A_4 中的 ⟨(12)(34)⟩）

#### 3.4 短正合列（预告 §6）🟣
- 1 → N → G → G/N → 1；裂解 ⇒ 半直积（§6 展开）

#### 🤖 机器人侧栏 3：齐性空间 SO(3)/SO(2) ≅ S²
- **ℝ³ ⊴ SE(3)**（平移正规）⇒ 商群 SE(3)/ℝ³ ≅ SO(3)
- **SO(2) ≤ SO(3) 不正规**，商非群，但作为 **齐性空间** SO(3)/SO(2) ≅ S² —— 摄像头/天线指向的 2 维流形
- "正规 → 商群，非正规 → 商集/齐性空间" 的分水岭是 Layer-1 齐性空间理论的起点；拓扑结构由 A3 商拓扑给出

### §4. 群作用 🔵

**主参考.** D&F 1.7, 4.1–4.4 · Artin 6.7–6.12 · Lang I.5 · Aluffi II.9, IV.1.

#### 4.1 作用的定义与等价描述 📖 🔵
- 左作用 G × X → X；等价于同态 ρ: G → Sym(X)
- 左 ↔ 右 作用的对应（x·g := g⁻¹·x）
- 传递、忠实、自由作用

#### 4.2 轨道-稳定子定理 📖 🔵
- 轨道 G·x；稳定子 G_x ≤ G
- **定理**：映射 gG_x ↦ g·x 给出双射 G/G_x ↔ G·x；有限时 |G·x| = [G: G_x]
- **Cayley 定理**：G ↪ Sym(G) 由左正则作用；每群皆为对称群之子群

#### 4.3 陪集作用与核 📖 🔵
- G 在 G/H 上作用；核 = core_G(H) = ∩_g gHg⁻¹ = H 中含的最大正规子群
- **重要推论**：[G:H] = n ⇒ G/core 嵌入 S_n —— 非单性常用杀器

#### 4.4 共轭作用与类方程 📖 🔵
- 共轭类；稳定子 = 中心化子 C_G(g)
- **类方程**：|G| = |Z(G)| + Σ [G:C_G(g_i)]
- **推论**：p-群有非平凡中心；p² 阶群 Abel

#### 4.5 Burnside / Cauchy–Frobenius 引理 📖 🔵 ⚡
- 轨道数 = (1/|G|) Σ_g |X^g|
- 应用：涂色/项链计数；多机器人分配的可区分配置计数

#### 🤖 机器人侧栏 4：构型空间的 SE(3) 与 SO(3) 作用
- **SE(3) ↻ ℝ³**（传递）；稳定子 = SO(3)；由轨道-稳定子：SE(3)/SO(3) ≅ ℝ³
- **SO(3) ↻ S²**（传递）；北极稳定子 = SO(2)；故 SO(3)/SO(2) ≅ S²
- **Stiefel 流形** V_k(ℝⁿ) = O(n)/O(n−k)（视觉 SLAM 特征正交基）
- **Grassmann 流形** Gr_k(ℝⁿ) = O(n)/(O(k)×O(n−k))（子空间跟踪、SfM）
- **等变性原理**：若代价 C、动力学 f 在 G 作用下不变，Pontryagin 最优性条件降到 Q/G，搜索空间缩小 |G| 倍
- **参考**：Absil–Mahony–Sepulchre, *Optimization on Matrix Manifolds* (Princeton 2008)；Ordoñez-Apraez 等, IJRR 2025

### §5. Sylow 定理 🔵

**主参考.** D&F 4.5, 6.1 · Artin 7.3–7.6 · Lang I.6 · Hung. II.5, II.6 · Aluffi IV.2.

#### 5.1 Cauchy 定理 📖 🔵
- p ∣ |G| ⇒ 存在 p 阶元（证明：McKay 计数 ℤ/p 在 G^{p} 上作用；或类方程归纳）

#### 5.2 Sylow 三定理（完整证明）📖 🔵
设 |G| = pᵃm, gcd(p, m) = 1；Syl_p(G) = Sylow p-子群集。
- **Sylow I（存在性）**：Sylow p-子群存在；更强：每个 pᵏ 阶子群存在（0 ≤ k ≤ a）
- **Sylow II（共轭与包含）**：所有 Sylow p-子群共轭；每个 p-子群含于某 Sylow p-子群
- **Sylow III（计数）**：n_p ≡ 1 (mod p) 且 n_p ∣ m；n_p = [G: N_G(P)]
- **证明策略**：I 类方程归纳（中心 p-阶元提升）；II P' 作用在 G/P 上数不动点 mod p；III P 作用在 Syl_p(G) 上

#### 5.3 小群分类应用 📖 🔵 ⚡
- pq 阶（p < q, p ∤ q−1 ⇒ 循环；p ∣ q−1 ⇒ 非 Abel 唯一）
- 完整分类 |G| ≤ 15（Hung. II.6 最清晰）
- 单性证明：orders 30, 56, 60 的 A_5 首个非 Abel 单群

#### 5.4 可解群预备 🟣
- 导出列；可解的等价条件；子群/商/扩张对可解性封闭
- 为 §14 Galois 可解性作铺垫

#### 🤖 机器人侧栏 5：SO(3) 的有限子群与分子/模块机器人
SO(3) 的有限子群分类（ADE 体系）：C_n（循环）、D_n（二面体）、T（四面体阶 12）、O（八面体阶 24）、I（二十面体阶 60）。证明用类方程 + Sylow 风格论证。应用于：
- **晶格/模块自重构机器人**的对称分析（M-TRAN、SMORES）
- **分子装配**的点群分类
- **ADE 分类**为 Layer-1 之后的根系/李代数分类预热

### §6. 直积与半直积 🔵

**主参考.** D&F 5.1, 5.4, 5.5 · Artin 2.11, 7.5 · Lang I.2 · Aluffi IV.5.

#### 6.1 外/内直积 📖 🔵
- 外直积 G × H（范畴积，§15 回顾）；万有性质
- 内直积识别：N, K ⊴ G, N ∩ K = {e}, NK = G

#### 6.2 半直积构造 📖 🔵 ⚡
- 给定同态 φ: H → Aut(N)，N ⋊_φ H 以 (n_1,h_1)(n_2,h_2) = (n_1 φ(h_1)(n_2), h_1 h_2) 为积
- **严格验证结合律**（非平凡，利用 φ 为同态）
- 逆元公式 (n,h)⁻¹ = (φ(h⁻¹)(n⁻¹), h⁻¹)

#### 6.3 半直积识别定理 📖 🔵
- N ⊴ G, H ≤ G, N ∩ H = {e}, NH = G ⇒ G ≅ N ⋊_φ H，φ(h)(n) = hnh⁻¹
- 等价于 1 → N → G → H → 1 **裂解**
- ⚠️ **严格点**：并非所有扩张都裂（ℤ/4 与 ℤ/2 × ℤ/2 均有 1→ℤ/2→·→ℤ/2→1，前者不裂）；由 H²(H, N) 分类（⬛ 前向指向）

#### 6.4 典型例子 📖 🔵 ⚡
- D_n ≅ ℤ/n ⋊ ℤ/2（反转作用）
- Aff(n, k) ≅ kⁿ ⋊ GL_n(k)
- Holomorph G ⋊ Aut(G)

#### 🤖 机器人侧栏 6（**本章核心应用**）：SE(3) = ℝ³ ⋊ SO(3)
**动作**：R ∈ SO(3) 作用在 t ∈ ℝ³ 上即标准矩阵乘 R·t = Rt。

**乘法规则**（对于 (t_1, R_1), (t_2, R_2) ∈ ℝ³ ⋊ SO(3)）：
$$(t_1, R_1) \cdot (t_2, R_2) = (t_1 + R_1 t_2,\ R_1 R_2)$$

**逆元**：$(t, R)^{-1} = (-R^\top t, R^\top)$

**4×4 齐次矩阵实现**：
$$\begin{pmatrix} R_1 & t_1 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} R_2 & t_2 \\ 0 & 1 \end{pmatrix} = \begin{pmatrix} R_1 R_2 & R_1 t_2 + t_1 \\ 0 & 1 \end{pmatrix}$$

—— 与半直积公式**逐字吻合**。应 **完整课堂推演**：验证群公理、导出逆元、证 ℝ³ ⊴ SE(3)、证 SO(3) 不正规、证 SE(3)/ℝ³ ≅ SO(3)。类似 SE(2) = ℝ² ⋊ SO(2) 用于平面移动机器人。

**为什么不是直积？** 因旋转与平移不可交换（先旋转后平移 ≠ 先平移后旋转），这正是半直积必需的全部理由。

**POE 公式**（Brockett 1984）：串联机械手前向运动学 $g_{st}(\theta) = e^{\hat\xi_1 \theta_1}\cdots e^{\hat\xi_n \theta_n}\cdot g_{st}(0)$，每个因子属 SE(3)；半直积的非交换性解释为何末端位姿依赖关节乘积次序。

**参考**：MLS 1994 Ch. 2–3；Lynch–Park 2017 Ch. 3；F. C. Park, IEEE TAC 39(3), 1994。

### §12. PID 上 f.g. 模的结构定理（**A2d 核心**）🔵

**主参考.** D&F 12.1–12.3 · Artin 14.4–14.8 · Lang III.7, XIV · Hung. VII.4–5 · Jac. BA I Ch. 3（全章）.

#### 12.1 结构定理的两种形式 📖 🔵
设 R PID，M f.g. R-模。
- **不变因子形式**：M ≅ Rʳ ⊕ ⊕_{i=1}^m R/(a_i)，a_1 ∣ a_2 ∣ … ∣ a_m 非零非单位（**不变因子**）；r 与 (a_i) 唯一
- **初等因子形式**：M ≅ Rʳ ⊕ ⊕_j R/(p_j^{e_j})，p_j 素（**初等因子** = 素数幂）；次序差异一致
- 两形式通过 CRT 互换

#### 12.2 存在性证明（Smith 标准型路线）📖 🔵 ⚡
1. f.g. 模给出呈现 Rⁿ →^A Rᵐ → M → 0
2. **Smith 标准型定理**：PID 上矩阵经可逆行/列运算等价于 diag(d_1,…,d_k, 0,…,0)，d_1 ∣ … ∣ d_k
3. 读出 M ≅ Rᵐ⁻ᵏ ⊕ ⊕_i R/(d_i)
4. **Smith 算法基于 PID 中 GCD 消元** —— F[x] 时即欧几里得除法

#### 12.3 唯一性 📖 🔵
- 自由秩 r = dim_K(K ⊗_R M)，K = Frac(R)
- **Fitting 理想**：d_1 … d_j = A 的所有 j×j 子式之 GCD（唯一性直接可读）
- 初等因子唯一性：dim_{R/(p)} (pᵏM/pᵏ⁺¹M) 决定

#### 12.4 应用 1：R = ℤ, f.g. Abel 群基本定理 📖 🔵
- A ≅ ℤʳ ⊕ ℤ/n_1 ⊕ … ⊕ ℤ/n_m，n_1 ∣ … ∣ n_m
- 有限 Abel 群分类

#### 12.5 应用 2：R = F[x]，有理标准型与 Jordan 型（**A2d 桥梁**）📖 🔵 ⚡

**设置.** V 为有限维 F-空间，T: V → V 线性；定义 p(x)·v := p(T)(v)。则：
- V 为 f.g. F[x]-模（任一 F-基生成）
- V **挠**（Cayley–Hamilton：特征多项式湮灭）；无自由部分
- 故 V ≅ F[x]/(f_1) ⊕ … ⊕ F[x]/(f_m)，f_1 ∣ … ∣ f_m 首一 —— **T 的不变因子**

**有理标准型 (RCF).** 每一柱状 F[x]/(f_i(x))（f_i = xᵈ + c_{d−1}x^{d−1} + … + c_0）取基 {1, x, …, x^{d−1}}，x 即 T 的矩阵为**友矩阵** C(f_i)；T 在整个 V 的矩阵为块对角 diag(C(f_1), …, C(f_m))。**RCF 在任何域 F 上存在，无需代数闭包。**

**Jordan 型.** 用初等因子形式：V ≅ ⊕ F[x]/(p_j(x)^{e_j})。**当特征多项式在 F 上分裂（特别 F 代数闭）** 时每 p_j 线性 = x − λ_j；基 {(x−λ)^{e−1},…,1} 给出标准 Jordan 块 J_e(λ) = λI + N。

**关键多项式恒等式（必背）**：

| A2d 对象 | F[x]-模化身 |
|---|---|
| 向量空间 V + 算子 T | 挠 f.g. F[x]-模 |
| T-不变子空间 | F[x]-子模 |
| 有理标准型 | 不变因子分解 |
| Jordan 标准型 | 初等因子分解（线性素元时）|
| T 的最小多项式 | 最大不变因子 f_m |
| T 的特征多项式 | ∏ f_i（所有不变因子之积）|
| Cayley–Hamilton | f_m ∣ χ_T 的平凡推论 |
| A, B 相似 ⟺ | xI − A, xI − B 有相同 Smith 型 |
| T 可对角化 ⟺ | 所有初等因子 e = 1（最小多项式无重根）|

⚠️ **严格点**：实域上无一般 Jordan 型，只有"实 Jordan 型"（2×2 块对应复共轭对）= RCF 不可约二次初等因子。

#### 🤖 机器人侧栏 12：Kalman 可控性的模论阐述
ẋ = Ax + Bu 使 ℝⁿ 为 ℝ[s]-模（经 A）；可控性矩阵 [B, AB, …, A^{n−1}B] 生成 F[x]-子模 = 可控子空间。**极点配置** = 选反馈 K 使 (A+BK) 的不变因子为指定。Jordan 型决定线性 ODE ẋ = Ax 的模态（指数、多项式、振荡）。Smith 型 over ℝ[s] 计算 DAE-型机器人动力学的不变量（描述子系统）。参考：Kailath 1980 §6。

- 不可约 f 可分 ⟺ f' ≠ 0 ⟺ (char 0) 或 (char p 且 f ≠ g(xᵖ))

- **本原元素定理**：有限可分扩张 = 单扩张 —— 🟣 分情况证（有限域 / 无限域）

#### 14.3 正规与 Galois 扩张 📖 🔵
- 正规 ⟺ 一根在 L 则所有根在 L ⟺ 为某族分裂域
- **Galois = 正规 + 可分**（有限）⟺ |Aut_K(L)| = [L:K]
- Gal(L/K) := Aut_K(L)

#### 14.4 Galois 基本定理（FTGT）🟣 ⬛

**陈述**（L/K 有限 Galois，G = Gal(L/K)）：
1. {中间域 K ⊆ F ⊆ L} ↔ {子群 H ≤ G}，F ↦ Gal(L/F), H ↦ L^H —— 反序双射
2. [L:F] = |H|；[F:K] = [G:H]
3. F/K 正规 ⟺ H ⊴ G；此时 Gal(F/K) ≅ G/H

**证明策略**：Artin 引理（|L : L^G| = |G|，用 Dedekind 字符线性独立）；⬛ 完整证留作参考材料（D&F 14.2）。

#### 14.5 例 📖 🔵
- ℚ(√2, √3)/ℚ：Gal ≅ (ℤ/2)²，5 个子群 ↔ 5 中间域
- ℚ(ζ_n)/ℚ：Gal ≅ (ℤ/n)^×（分圆）
- x³ − 2 分裂域：Gal ≅ S_3（非 Abel）
- 𝔽_{p^n}/𝔽_p：Gal ≅ ℤ/n（Frobenius 生成）

#### 14.6 可根式解与可解群 🟣
- 可解群：导出列终止 —— 回顾 §5.4
- **Galois 定理**：f 可根式解 ⟺ Gal(f/K) 可解（char 0）；前向证，反向 ⬛
- **Abel–Ruffini**：n ≥ 5 通用多项式不可根式解（S_n 非可解 for n ≥ 5）

#### 14.7 古典不可能性 📖 🔵
- 规尺可构造 ⟺ [ℚ(α):ℚ] 为 2 的幂
- 三等分角（cos 20° 度数 3）、倍立方（∛2 度数 3）、化圆为方（π 超越 ⬛ Lindemann）

#### 🤖 机器人侧栏 14：Galois 与 6R 逆向运动学可解性
- **Raghavan–Roth 1993**：一般 6R 机械手 IK 归结为半角切 u 的 16 次一元多项式；16 > 4 ⇒ 通用情形 **不可根式解** ⇒ 无通用闭式 IK 公式
- **Pieper 判据 (1968)**：三连续轴相交（球腕）或平行 ⇒ IK 解耦为位置（≤ 4 次）+ 方向（3 角）⇒ **可根式解** ⇒ 闭式 IK 存在
- **工业后果**：PUMA、UR、KUKA、Staubli 等均采球腕设计以换取实时闭式 IK
- **一般 6R 替代**：Gröbner 基、Dixon 结式、同伦延拓、Newton（数值迭代）、IK-Geo 规范子问题分解（Elias–Wen 2022, arXiv:2211.05737）
- 参考：Raghavan & Roth, 5th ISRR 1990；Manocha & Canny, IEEE T-RA 10(5), 1994

### §15. 范畴论 🔵 / 🟣

#### 15.1 范畴：定义与例 📖 🔵

**定义**（局部小范畴）：对象类 Ob(𝒞)；每对 (A, B) 的态射集 𝒞(A, B)；可结合的合成；恒等 id_A。

**例库（必熟）**：Set, Grp, Ab, Ring, Mod_R, Vect_k, Top, Top*, Man, 偏序集 P, 单对象 BG（群 G 之态射集）。

**大小**：小（Ob 为集）、局部小（Hom 为集）—— A1 集合论钩连。

#### 15.2 函子 📖 🔵
- 协变 F: 𝒞 → 𝒟；反变 = 协变 𝒞^op → 𝒟
- **例**：忘却 U；自由左伴随 F；Hom-函子 𝒞(A, −)；张量 − ⊗ M；对偶 (−)^* **（A2 钩连）**；**切丛 T: Man → VectBundle（机器人核心）**；基本群 π_1

#### 15.3 自然变换 📖 🔵
- η: F ⇒ G：态射族 η_A 使方形交换
- **典范例 A2**：V ≅ V^** **自然**；V ≅ V^* **非自然**（依赖基） —— 对偶理论精髓
- 函子范畴 [𝒞, 𝒟]

#### 15.4 万有性质 📖 🔵

#### 15.5 极限与余极限 🟣

#### 15.6 伴随函子 🟣 / 🔵
- F ⊣ G ⟺ 自然同构 𝒟(F(A), B) ≅ 𝒞(A, G(B))

#### 15.7 Yoneda 引理 ⭐🟣 （**必完整证明**）

**陈述**：对局部小 𝒞、A ∈ Ob(𝒞)、F: 𝒞 → Set：
$$\operatorname{Nat}(\mathcal{C}(A, -), F) \cong F(A), \text{ 自然双变}$$

**推论（Yoneda 嵌入）**：𝒞 ↪ [𝒞^op, Set]，A ↦ 𝒞(−, A)，完全忠实 —— **"对象由其态射系统决定"**。

**证明（简短而启发）**：
- Φ(η) := η_A(id_A)；Ψ(x)_B(f) := F(f)(x)
- 自然性方形验证；Φ ∘ Ψ = Ψ ∘ Φ = id 直接计算

**意义**：表示函子体现对象本质；函子式观点（Grothendieck）；机器人方法论：SO(3) 无论以旋转矩阵/四元数/轴-角/Euler 表示，**对象本身由其映射系统决定** —— 表示转换须为自然变换。

### 🏁 结语：代数骨架之于机器人学

抽象代数在本课程中并非装饰，而是 **机器人数学的底层骨架**。SE(3) 作为半直积不是一个"漂亮的观察"，而是决定了运动学非交换性、POE 公式合法性与位姿空间全局拓扑的**唯一正确代数结构**。PID 上 f.g. 模结构定理是 Kalman 模论式控制、极点配置 Bézout 算法与 Jordan 模态分解的**统一源**。范畴论不是炫学，而是**代码正确性**的保障 —— 保证四元数-矩阵-轴角转换互相兼容；保证切丛函子产生一致的动力学。Galois 可解性更罕见地直接决定工程：**球腕设计**之所以普遍，正因为非球腕 6R 机械手的 IK 多项式 Galois 群不可解，闭式解不存在。

### 从代数到分析：Batch A 与 Batch B 的交界

至此，代数/拓扑支柱（Batch A：A1 集合论 → A2 线性代数 → A3 拓扑 → A4 抽象代数）已全部完成。读者已经建立了一套**离散—结构—不变量**的代数直觉：群作用分类对称性、环与模统一标准型、范畴论组织转换。接下来进入的分析支柱（Batch B：B1 实分析 → B2 测度论 → B3 泛函分析 → B4 ODE）将提供截然不同的**连续—收敛—逼近**的分析直觉。

这一转换并非割裂——恰恰相反，Batch A 的产出是 Batch B 的原料。A1 的 ZFC 与选择公理为测度论的可数可加性和 Hahn-Banach 的延拓提供逻辑地基；A2a/b/d 的赋范空间、内积、谱分解是实分析和泛函分析的核心例子来源；A3 的度量空间、紧性、Baire 纲定理直接支撑 B1 的一致收敛理论和 B3 的三大支柱；A4 的环论为函数环 $C(X)$ 的代数结构、PID 上的模结构定理与线性 ODE 解空间的关联埋下伏笔。两条支柱在 B3 泛函分析处汇合——这正是第零层的设计核心。

根据 Mayer 双编码理论，代数直觉与分析直觉使用不同的认知通道，相互干扰小。如果读者按照"双车道并行"方案学习，此时可能已经在车道二上启动了 B1 或 B4。无论串行还是并行，此处的认知模式切换——从"构造不变量以分类结构"转向"用 epsilon-delta 追踪逼近过程"——是第零层最重要的思维跃迁之一。
