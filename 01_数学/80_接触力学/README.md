# 接触力学（第七批）

> **导读**：本目录覆盖接触力学与混合动力系统的完整理论链。整条叙事的主轴可以用一个问题串起来："一只脚踩到地面这件事，到底怎么让计算机算清楚？" 每个专题都是这个问题在不同抽象层次上的回答，从"接触是什么"一直追到"把接触塞进学习与控制的闭环还剩多少理论缺口"。
>
> 7 个专题按依赖顺序排列：互补问题建立法向接触的数学模型，摩擦锥将其推广到切向，时步法解决数值积分，可微接触仿真打通梯度，混合动力系统处理模式切换，接触隐式轨迹优化连接控制，非光滑分析提供理论基础。
