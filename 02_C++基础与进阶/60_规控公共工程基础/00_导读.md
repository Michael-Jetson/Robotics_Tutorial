# 规控公共基础与体系架构

> **版本**：合并版 v1 | **合并日期**：2026-04-27
> **来源文件**：5个源文件合并（方向分类 + 30章扩展方案 + C++横向工程全景 + 库生态调研 + 论文脉络全景）
> **适用对象**：完成 v8/v10 SLAM主线后，准备切入规控方向的工程师
> **定位**：规控教学体系的顶层架构设计与跨方向参考文献

### 导读

本文档由五个互补的源文件合并而成，共同构成规控教学体系的顶层知识框架：

1. **方向分类与公共基础层设计方案**——定义四大方向（无人机/机械臂/足式/复合体）的划分逻辑、公共基础层（Part 0）的十个主题，以及推荐学习路径。这是整个教学体系的"骨架"。
2. **30章扩展方案**——在方向分类的基础上，以C++工程知识点为主线设计30章教学大纲，每章对比无人机与机械臂两个领域的标杆开源项目。这是教学体系的"课程蓝图"。
3. **C++横向工程技术全景**——深入剖析数值优化、实时编程、无锁并发、ROS2架构等八大横向工程主题，为30章大纲提供技术细节支撑。这是教学体系的"技术底座"。
4. **库生态调研**——系统覆盖8大库类别、50+核心库，回答"规控工程师需要掌握哪些C++库"这一核心问题。这是教学体系的"工具箱清单"。
5. **论文脉络全景**——梳理五大方向共110+篇经典论文的演进脉络，为每个方向提供从开山之作到当前SOTA的完整学术地图。这是教学体系的"理论根基"。

五个部分的关系是：方向分类提供架构 → 30章方案与横向技术全景填充内容 → 库生态调研指导工具选型 → 论文脉络全景提供学术纵深。建议首先通读第一部分把握全局，再按需深入后续部分。
